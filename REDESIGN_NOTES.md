# Redesign Grupo W3

Branch de desenvolvimento: `redesign-enterprise-2026-08-29`.

## Objetivos
- elevar percepção enterprise da marca;
- unificar identidade visual em preto, azul e ciano;
- reduzir aparência de template genérico;
- explicar melhor a proposta integrada de cibersegurança + infraestrutura;
- melhorar navegação, conversão e responsividade;
- evitar dependência de imagens externas na home;
- manter o logo versionado no próprio projeto.

## Principais mudanças
- novo hero inspirado na referência fornecida, adaptado para cibersegurança;
- pipeline animado de dados → infraestrutura → proteção;
- faixa de capacidades integradas;
- novo portfólio de 12 serviços com hierarquia visual única;
- nova seção de operação de segurança (detectar, priorizar, responder, recuperar);
- nova seção institucional com mapa visual de proteção;
- novo fluxo de contato via WhatsApp com comunicação transparente;
- novo footer;
- novo template para todas as páginas internas de serviços;
- CSS responsivo para desktop, tablet e mobile.

## Segurança de publicação
A branch `main` não deve receber o redesign até revisão visual e validação de build.
